# MVP 范围与实现状态

## 目标用户

需要对研究、开发、审计、文档或交付任务进行过程留痕和质量复盘的个人与小团队。

## 核心数据模型

### Task

- `id`：任务标识
- `title`：任务名称
- `owner`：负责人
- `status`：`todo`、`doing`、`done`
- `priority`：`low`、`medium`、`high`
- `dueDate`：截止日期
- `summary`：任务目标或完成说明
- `archivedAt`：归档时间（归档任务仍可通过筛选查看）
- `evidenceIds`：关联证据
- `review`：质量复盘评分与备注

### Evidence

- `id`：证据标识
- `label`：证据名称
- `type`：文件、链接、测试、截图、访谈或其他
- `source`：路径、URL 或来源说明
- `note`：证据解释
- `verified`：是否已人工核验
- `localPath`、`sizeBytes`、`sha256`：本地文件证据的复制路径、大小和内容哈希

## 已实现

- FastAPI + SQLite 本地后端与健康检查
- Vue 3 + Vite + TypeScript 单页工作台
- 任务创建、列表、状态流转和优先级
- 任务编辑、归档、恢复可见和带确认的单任务删除
- 必需验收项与 completed 状态保护
- 文件、Git diff、测试输出、截图、网页链接、人工说明等证据录入
- 证据未审核、已确认、已拒绝、已过期状态
- JSON、JSONL、Markdown 运行记录导入、重复导入拒绝和事务回滚
- 导入内容只解析和展示，不执行命令或脚本
- 完成度、证据充分性、验证状态、执行情况、风险静态标记
- 任务时间线：证据、运行记录、评测和人工复盘按时间聚合
- 运行记录详情：步骤、工具调用、变更文件和测试结果时间线
- 任务对比：测试通过率、耗时、工具调用、风险标记、未完成验收项，以及每次运行的逐次明细
- 真实文件证据复制到 `data/evidence/`，记录文件大小和 SHA-256
- Vitest 前端组件测试与 Playwright 端到端测试配置
- Markdown / JSON 报告、人工复盘、待人工确认经验候选
- 带版本号的 JSON 数据备份导出与显式确认后的事务性恢复
- 用户主动触发的外部链接可达性检查，保存检查状态、HTTP 状态码和时间
- `backend\app.migrations` 提供 schema `status` / `upgrade` 命令，并同步 SQLite `user_version`
- `#task/{id}` 独立任务详情视图与任务中心式证据关联图
- 对比条形指标、风险/未完成项/多次运行筛选
- 增强 Markdown 报告和 HTML 打印版（浏览器可另存为 PDF）
- 批量复盘报告：将选中的多个任务按独立章节聚合为一份 Markdown 文档
- 关键变更审计日志：创建、更新、归档、删除、证据检查/复制、运行导入、评测、人工复盘和备份恢复均可追溯
- schema v2：审计日志单独迁移，JSON 备份同时包含审计记录
- schema v3：任务模板独立迁移，模板数据也纳入 JSON 备份
- schema v4：任务搜索 FTS5 索引与增删改触发器；中文/混合关键词保留 LIKE 回退，避免改变本地搜索语义
- 任务模板：保存目标、优先级、完成依据、验收项和证据类型，可一键实例化任务
- 服务端任务搜索与计数查询优化，避免列表加载时按任务逐条查询统计
- ASCII 关键词使用 FTS5、列表支持 `limit/offset` 分页，搜索输入按词转义以避免 FTS 查询语法注入/错误
- SQLite 连接统一启用 WAL、busy timeout、NORMAL synchronous 和本地连接缓存配置
- 前端请求层统一处理超时、网络错误、JSON/文本响应和后端结构化错误
- 首屏数据并行加载、任务搜索防抖、证据关系图异步分包
- 前端请求统一超时、网络错误和结构化 422 错误形态
- 默认本地免鉴权；可选 API Key、固定窗口限流、安全响应头和 CORS 配置
- `backend/scripts/performance_smoke.py` 提供临时数据库上的可重复趋势基线
- 前端已将任务列表、任务详情、任务模板和任务对比拆为独立组件，保留 hash 详情入口以兼容当前 MVP
- 公网部署第一阶段：Caddy HTTPS + oauth2-proxy/OIDC 边界模板、生产 profile 校验、Trusted Host、可信代理启动参数和安全 Cookie/HSTS 策略

## 明确不包含

- 账号系统、团队权限和服务端同步
- 自动判定证据真实性
- 自动提交、自动发布或绕过第三方平台限制
- 生产级审计合规承诺

## 尚未完成或需要加强

- 当前详情视图使用 hash 导航，尚未拆分为真正的多路由页面
- 证据图只表达“记录属于任务”的结构关系，不自动推断证据之间的因果关系
- PDF 目前依赖浏览器打印/另存为 PDF，不承诺服务端生成排版一致的 PDF 文件
- 当前 ASCII 搜索已使用 FTS5，中文/混合关键词仍使用参数化 `LIKE` 回退；任务规模继续增长后需要评估更适合中文的 tokenizer、相关性排序与索引重建
- 可选 API Key 和进程内限流只适合本地/临时局域网保护，不等于账号鉴权、对象级权限或多进程/分布式限流
- `deploy/` 第一阶段模板仍不提供 FastAPI 内部账号、会话撤销、角色权限或对象级授权；OIDC 入口登录不等于业务授权
- 性能脚本是本地结构基线，不代表生产 RUM、压力测试、网络延迟或多进程部署结果

## 后续路线

1. 真正的多路由任务详情页
2. 支持任意任务多选的批量复盘导出入口
3. 更丰富的证据关系类型，但仍保持人工确认边界
4. 多用户权限、角色策略和更细的审计留存策略
5. 任务详情、任务列表、模板、对比面板拆分为可维护的前端组件/路由
